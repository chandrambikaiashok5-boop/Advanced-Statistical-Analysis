# Advanced Statistical Analysis & Hypothesis Testing

## Internship Task 3

### Project Overview
This project performs inferential statistical analysis on the Student Performance Dataset using Python.

### Statistical Techniques
- Shapiro-Wilk Normality Test
- Kolmogorov-Smirnov Test
- Two-Sample T-Test
- Mann-Whitney U Test
- One-Way ANOVA
- Two-Way ANOVA
- Tukey HSD Post-Hoc Analysis
- 95% Confidence Intervals

### Technologies Used
Python, Pandas, NumPy, SciPy, Statsmodels, Matplotlib and Seaborn.

### Dataset
Student Performance Dataset from Kaggle.

### Project Output
A Jupyter Notebook containing statistical tests, visualizations and findings.
